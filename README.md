## Technology
- Python
- Flask
- MySQL
- HTML/CSS
- Bootstrap CDN

## Main DBMS concepts demonstrated
- Primary keys and foreign keys
- CRUD operations
- INNER JOIN and LEFT JOIN
- Aggregate functions
- Trigger
- Referential integrity
- Normalized relational tables

## Setup

1. Install MySQL Server and MySQL Workbench.
2. Open `schema.sql` in MySQL Workbench.
3. Execute the entire file.
4. Install Python 3.10+.
5. Open a terminal in this project folder.
6. Run:
   `python -m venv venv`
7. Activate the environment:
   Windows:
   `venv\\Scripts\\activate`
   Linux/macOS:
   `source venv/bin/activate`
8. Install packages:
   `pip install -r requirements.txt`
9. Open `app.py` and change `YOUR_MYSQL_PASSWORD` to your MySQL root password.
10. Run:
   `python app.py`
11. Open:
   `http://127.0.0.1:5000`
